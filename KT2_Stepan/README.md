# КТ №2 - Перегрузка индексаторов (Вариант 1: Playlist)

Решил делать первый вариант с плейлистом. Основная суть - сделать так, чтобы к объекту можно было обращаться как к массиву, но с разными параметрами (по номеру и по названию).

Что сделал:
1. Создал класс `Playlist`, внутри него спрятан список строк `List<string> tracks`.
2. Добавил метод `Add`, чтобы просто добавлять треки.
3. Сделал первый индексатор `this[int position]` - он умеет и читать, и записывать. Если передать номер, которого нет (например, -1 или 100), кидает `ArgumentOutOfRangeException`.
4. Сделал второй индексатор `this[string title]` - только для чтения. Если передать название трека, он возвращает его номер в списке. Если такого нет - возвращает -1.
5. Переопределил `ToString()`, чтобы выводить красивую строку вида `0: Track A, 1: Track B`.

Как работает:
-Из-за того, что индексаторы перегружены, компилятор сам понимает, какой из них вызывать. Если в скобках `[]` пишем число (`playlist[0]`) - работает первый. Если строку (`playlist["Track A"]`) - второй.
-В первом индексаторе есть проверки границ (`position < 0 || position >= tracks.Count`), чтобы нельзя было выйти за пределы списка. Если это происходит, программа не падает молча, а выбрасывает понятную ошибку.
-Поиск по названию сделан через стандартный метод `IndexOf`, который как раз возвращает нужный индекс или -1.
